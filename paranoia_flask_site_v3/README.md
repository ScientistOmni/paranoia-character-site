# Flask 能力値決定サイト（試作版）

## 起動手順（Windows / VS Code）

1. ZIPを展開し、そのフォルダをVS Codeで開きます。
2. ターミナルで以下を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:PLAYER_COUNT="1"
$env:ROOM_CODE="身内で共有するルームコード"
$env:FLASK_SECRET_KEY="推測困難な長いランダム文字列"
python app.py
```

ブラウザで http://127.0.0.1:5000/login を開きます。

## 参加人数の設定

`PLAYER_COUNT` 環境変数で設定します。指定できる人数は **1〜10人** です。

- **1人で画面をテストする場合**：`$env:PLAYER_COUNT="1"`
- **本来のアルゴリズムを動かす場合**：参加人数に合わせて `2`〜`10` を設定します。通常の身内セッションでは元の設定と同じ `7` 人なら `$env:PLAYER_COUNT="7"` です。
- 環境変数を設定しない場合は、既定値の7人です。

人数を変更して再起動すると、古い人数で保存した `game.db` のゲーム状態は自動的に初期化されます。同じ人数のまま最初からやり直したい場合は、サーバーを停止してから `game.db` をバックアップのうえ削除し、再起動してください。

## 1人テストモードの仕様

1人では「次のプレイヤーに同じ能力値の逆符号を付ける」という元のアルゴリズムの前提が成立しません。そのため、1人モードは**本来の能力割当を検証するモードではなく、Webサイトの画面遷移・フォーム送信・5ラウンドの進行を試すためのモード**です。

1人モードでは、入力・提出・結果確認・最終画面への遷移は行いますが、能力値とXPは変化しません。最終能力値の厳密検証も意図的にスキップします。最終画面にはテストモードである旨を表示します。

## 機能

- `ability_allocator.py` の `solve_step()` と `validate_final()` を使用します。
- A1〜A16、5ラウンド、初期XP100です。
- ルームコード＋プレイヤー番号＋表示名による簡易ログインです。
- 全員が「開始」を押すと第1ラウンドが始まります。
- 各ラウンドで希望能力（1〜3個）と入札XPを入力します。
- 全員提出後に計算し、全員分の割当結果と各自の能力値・XPを表示します。
- 全員が結果確認ボタンを押すと次のラウンドへ進みます。
- 最終ラウンド後に、通常モードでは `validate_final()` を実行します。
- ゲーム状態はSQLiteの `game.db` に保存されます。

## 簡易テスト

依存関係をインストールした後、`PLAYER_COUNT=1` でサイトを起動せずに一連の画面遷移を確認できます。

```powershell
python smoke_test_single_player.py
```

このテストは一時データベースを使うため、実際の `game.db` を変更しません。

## 注意

- 初期ルームコードは `CHANGE-ME` です。必ず `ROOM_CODE` を設定してから参加者に共有してください。
- `FLASK_SECRET_KEY` も必ず設定してください。
- ログアウトしてもプレイヤー枠は解放されません。Cookieを失った場合は、サーバー停止後に `game.db` をバックアップして削除し、再起動するとリセットできます。
- `127.0.0.1` は自分のPCからしかアクセスできません。友人も別のPCから使うにはホスティングサービスへの公開が必要です。
- `debug=True` はローカル開発専用です。公開環境では本番用WSGIサーバーを使い、HTTPS・CSRF対策・個別認証・永続ストレージを設定してください。
